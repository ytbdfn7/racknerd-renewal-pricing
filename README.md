## 怎么续费——四步操作

系统默认会在到期前两周自动生成续费账单，发到注册邮箱。如果想提前续费，手动操作也很简单：

1. **登录后台** → 进入"Services"（服务）列表页面
2. **点击要续费的 VPS** → 进入该服务详情页
3. **找到左侧"Actions"（操作）栏** → 点击"Generate Renewal Invoice"（生成续费账单）
4. **点击生成的账单链接** → 核对金额，完成支付

支付完成后续费立刻生效，服务周期顺延一个计费周期。整个流程几分钟内完成，账单上的金额就是你当初下单时的价格。

顺便说一下：如果是年付套餐，建议到期前一两周主动处理一下，别等到最后一天。邮件提醒有可能漏看，服务中断后重新激活会有额外麻烦。

## 续费同价一个容易误解的地方

有人以为"续费同价"等于"账号永久有效，随时可以续"。方向是对的，但有个前提不能忽略：

续费同价锁定的是**这个套餐持续运行期间的价格**。如果套餐到期后没有及时续费，服务被暂停，之后想重新激活，不一定能按原活动价处理——相当于重新下单，走当时现行的价格。

所以续费同价的保障前提是**持续续费、不断档**。活动套餐到期前生成的那笔账单，金额和第一年完全一样——这不是 bug，是官方政策。用下来这点体验挺踏实的，不用担心哪天账单突然多出一大块。

## FAQ

**Q：续费的时候价格会比首次购买贵吗？**

不会。RackNerd 的续费政策是按购买时的价格出账单，不涨价。活动套餐续费同样适用，账单金额和最初下单时一样。

中断后的情况不好说，不一定能保住原活动价。建议在账单到期前主动处理，系统会在到期前两周发提醒邮件，记得查收。

**Q：RackNerd 支持哪些付款方式？**

支持 PayPal、信用卡、支付宝，国内用户付款基本没有障碍。

**Q：买了特价套餐之后能升级配置吗？**
