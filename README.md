## 续费同价的机制是什么

不是"续费享折扣"，不是"前两年锁价"。是真的**按你首次购买时的价格出续费账单，一直锁定，不因时间推移或官网调价而变动**。

这个机制的实际意义是：越早在活动期间买入，锁定的成本越低。续费同价的套餐对于长期使用的用户来说，时间越长越划算。换到别家反而多花钱，这也是为什么很多人续了好几年还没走。

## 怎么操作续费——四步搞定

系统默认会在到期前两周自动生成续费账单，发到你注册邮箱。不想等系统提醒的话，也可以手动提前续费：

1. **登录后台** → 进入"服务"（Services）列表页面
2. **点击要续费的服务** → 进入该 VPS 的详情页
3. **找到左侧"操作"（Actions）栏** → 点击"生成续费账单"（Generate Renewal Invoice）
4. **点击账单链接** → 核对金额，完成付款

付款后续费立刻生效，服务周期顺延一个计费周期。整个流程几分钟内完成。

顺便提一嘴：如果你的套餐是按年付的，建议在到期前一两周主动续费，免得因为邮件没看到导致服务中断。中断后重新开机会有一定时间成本。

## 续费同价的一个容易误解的地方

有人以为"续费同价"的意思是"永远不会涨价"，这个理解方向是对的，但有个细节要说清楚。

续费同价锁定的是**你这个账户下这个套餐的价格**。如果你的套餐到期没续，系统暂停服务，等你后来想重新激活，可能就不按原来的活动价走了——相当于重新下单，就是当时现行的价格。

所以续费同价的保障前提是：**持续续费，不断档**。

活动套餐到期前的那笔续费账单，你会发现金额跟第一年完全一样。这不是系统 bug，是官方政策。用过的人对这点的评价普遍都不错，觉得省心。

## FAQ

**Q：续费的时候价格会比首次购买高吗？**

不会。RackNerd 的政策是续费按首次购买时的价格计算，不涨价。系统自动生成的账单金额和你最初下单时一样。

**Q：活动套餐的续费也是同价吗？**

是的。黑五、新年、双十一等活动套餐同样适用续费同价政策。这类套餐一旦买到，后续每年续费都是活动价，这也是为什么很多人会专门等活动再入手。

**Q：错过续费了，服务中断了，还能按原价续吗？**

服务中断后的情况比较复杂，不保证能原价续费。建议在账单到期前主动处理，不要拖到最后。系统会在到期前两周发邮件提醒，记得查收。

**Q：RackNerd 支持哪些付款方式？**

支持 PayPal、信用卡、支付宝，国内用户付款基本没有障碍。

**Q：买了特价套餐之后能升级配置吗？**

可以升级到更高一档的套餐，升级时会按差价补费。但要注意，升级后的续费价格按新套餐的价格计算，不再是原活动套餐的价格。如果当前配置够用，没必要为了"升级"把已经锁定的低价弄没。
